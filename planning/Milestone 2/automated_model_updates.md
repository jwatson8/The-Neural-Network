# Automated model updates

Our Docker Compose deployment includes a daily updater scheduled for 2:00 a.m. Eastern time. It combines the original course dataset with accumulated production interactions from PostgreSQL, validates and deduplicates the records, and retrains our 32-factor SVD recommender. Each run saves its data snapshot, model versions, evaluation results, and decision reasons for reproducibility.

To avoid training on the answers used for testing, an evaluation candidate learns only from data available before the previous day. Both the candidate and current model are evaluated on that day's held-out ratings using NDCG@20 and Recall@20. Eligibility requires at least 100 evaluated users, evidence of improved NDCG from paired bootstrap comparisons, inference p95 below 600 ms, and passing distribution-drift checks. Missing data or failed checks leave production unchanged. If eligible, a separate final model is trained through the end of the previous day, including its new interactions.

Retraining and evaluation are automatic; deployment requires a teammate's approval. The promotion command verifies the candidate, backs up the current model, replaces its artifact, and restarts the API. It checks the loaded model's checksum and a recommendation response; failed verification triggers rollback. This accepts a brief restart interruption in exchange for a simple, recoverable deployment.

Implementation: [training and evaluation](https://github.com/jwatson8/The-Neural-Network/tree/main/src/model_updates), [Compose scheduling service](https://github.com/jwatson8/The-Neural-Network/blob/main/compose.yaml), and [promotion/rollback script](https://github.com/jwatson8/The-Neural-Network/blob/main/deployment/daily_model.sh). The [runbook](https://github.com/jwatson8/The-Neural-Network/blob/main/deployment/DAILY_MODELS.md) documents data prerequisites and commands. Production ingestion must populate PostgreSQL before daily retraining can use live interactions; successful production updates must be verified on the VM.
