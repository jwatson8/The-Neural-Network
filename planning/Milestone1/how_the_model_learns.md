# How our model works and learns

Our model learns from users' movie ratings and viewing history using collaborative filtering, which finds patterns across many people's preferences. During training, a method called SVD summarizes these patterns into a 32-number "fingerprint" for each user and movie. To recommend movies, it compares the user's fingerprint with movie fingerprints and returns the highest-scoring movies the user has not already watched or rated in the training data. For users without history, our cold-start approach uses an LLM to interpret their written likes and dislikes, then matches those preferences to movie descriptions; without a usable profile, it recommends popular movies. As we collect more interactions, retraining recalculates the user and movie fingerprints. Adding accounts alone does not teach the model, and retraining is not automatic in our current deployment. More data may improve recommendations, but we must test each new model to confirm that it does.
